# Примеры

| Папка | Файл | Что это |
|---|---|---|
| `kingdom` | `KINGOM.PAS` | «Королевство Эйфория» — текстовая экономическая стратегия |
| `stalker` | `STALK.PAS` | «Сталкер» («Зона») — бродилка по подземельям по мотивам «Пикника на обочине» |
| `leibniz` | `LEIBNZ.PAS` | вычисление числа π рядом Лейбница, 10000 членов ряда |
| `sieve` | `SIEVE.PAS` | решето Эратосфена — классический тест скорости: 10 проходов, простые числа до 16383 |

Исходники в кодировке КОИ-8Р.

## Игры

Две игры для ДВК и УКНЦ, написанные в конце 1980-х на OMSI Pascal 1 («Паскаль ДВК»). Их исходники восстановлены по исполнимым файлам ([uknc-various](https://github.com/nzeemin/uknc-various): `KINGOM-PASCAL`, `STALK-PASCAL`) и здесь перенесены на диалект Turbo Pascal 3.0 для Pesto/11.

Тексты «Королевства» написаны латиницей в КОИ-7: после символа `#14` (SO) терминал УКНЦ показывает строчные латинские буквы как русские.

## Сборка

```
pesto11 KINGOM.PAS
macro11 KINGOM.MAC -o KINGOM.OBJ -rt11
macro11 PESTO.MAC -o PESTO.OBJ -rt11
pclink11 KINGOM.OBJ PESTO.OBJ -EXECUTE:KINGOM.SAV
```

`KINGOM.SAV` запускается под RT-11 на УКНЦ: `RU KINGOM`. «Сталкер» собирается так же из `STALK.PAS`.

## Что изменено при переносе

Общее для обеих игр:
- восьмеричные константы `33B` стали десятичными;
- строки, разбитые на несколько строк исходника, записаны через `#13#10`;
- `WRITE` строковой константы длиннее 255 символов разбит на несколько: в TP3 строка не длиннее 255.

«Королевство»:
- модули `KINGM2`…`KINGM6` собраны в один файл, объявления `external` убраны;
- `FLOAT(x)` — просто `x`, Integer в Real преобразуется сам;
- псевдоним правителя — `string[10]`, дополненный пробелами до 10 символов, как массив символов OMSI;
- таблица рекордов `KING.DAT` читается и записывается через типизированный файл TP3. В оригинале файл читался и переписывался одновременно через буферы `D^`/`E^` и `GET`/`PUT`.

«Сталкер»:
- ассемблерные вставки `{$C …}` стали `asm … end`;
- `@X` — `Ptr(Addr(X))`, операция `&` — `and`;
- `RANDU` из библиотеки Фортрана заменена на `Random`.

## Ряд Лейбница

π/4 = 1 − 1/3 + 1/5 − 1/7 + … Программа печатает частичную сумму, умноженную на 4, через каждые 1000 членов, а в конце — среднее двух соседних сумм: оно гораздо ближе к π.

Программа написана на общем подмножестве Turbo Pascal 3.0 и OMSI Pascal 1, без правок компилируется обоими. Вывод программ, собранных Pesto/11 и OMSI Pascal, совпадает до цифры (`3.1415000`, среднее `3.1416000`). Тест `0543-prog-leibniz` проверяет вывод в эмуляторе.

## Решето Эратосфена

Классический тест компиляторов Pascal: флаги нечётных чисел 3…16383 (`FLAGS[I]` — число `2·I+3`), 10 проходов, в конце — число простых. Программа общая для Pesto/11 и OMSI Pascal, обе печатают 1899. Тест `0544-prog-sieve` проверяет вывод в эмуляторе.

## Размер кода

Эти программы — эталон для сравнения с OMSI Pascal (DESIGN.md §7.11): код программы Pesto/11 занимает около 74% слов кода OMSI. Повторить замер: `python tools/codesize.py ПАПКА_uknc-various`.
