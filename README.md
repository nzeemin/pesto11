# Pesto/11

Кросс-компилятор с диалекта **Turbo Pascal 3.0** в ассемблер **PDP-11** (MACRO-11) для советских PDP-11-совместимых машин.

- Первая цель: УКНЦ (Электроника МС 0511) под RT-11. Полученный `.MAC` собирается ассемблером `macro11` и компонуется `pclink11` в `.SAV`.
- Позже: БК-0010 с ассемблером BKTurbo8.

**Состояние:** версия 0.2.0. Поддержан почти весь язык TP3: выражения и операторы, процедуры и функции (рекурсия, вложенность, `forward`, `external`), массивы, записи, указатели и куча, строки, множества, Real (DEC F, 4 байта, через FIS), ввод с консоли, экран и клавиатура, текстовые, типизированные и нетипизированные файлы RT-11, директивы `$R`, `$I`, `$V`, `$B`, ассемблерные вставки `asm … end`; из TP4 — `Inc`/`Dec`. Код оптимизируется в генераторе и проходом peephole. Не поддерживаются `inline`, `overlay`, `Chain`/`Execute`, `Port`, `Bdos`/`Bios`, `Aux`/`Usr`, `Lst` (пока). Все отличия от TP3 — в [`docs/TP3-dialect.md`](docs/TP3-dialect.md), §12.

Код получается заметно компактнее, чем у OMSI Pascal (родной компилятор Pascal для ДВК и УКНЦ): на примерах из [examples](examples/) — около 71% слов кода, а полный образ `.SAV` с рантаймом — около 66% байт.

## Сборка

Нужен компилятор C++17, других зависимостей нет. Компилятор собирается:

- **Linux** — GCC или Clang;
- **macOS** — Clang;
- **Windows** — Visual Studio 2022 (MSVC).

Все четыре варианта собираются и проходят тесты компилятора в CI (GitHub Actions).

Linux / macOS:

```sh
make
make test
```

Компилятор выбирается переменной `CXX`, например `make CXX=clang++`.

Windows: открыть `pesto11-VS2022.sln` в Visual Studio 2022, собрать, затем из корня репозитория запустить `!tests-run.cmd` (по умолчанию тесты сборки Debug; для другой — `set CONFIGURATION=Release`). Release собирается со статическим рантаймом C++: `pesto11.exe` зависит только от `KERNEL32.dll`, ставить ничего не нужно.

Тесты, которые собирают `.SAV` и запускают программу в эмуляторе УКНЦ, работают, только если рядом лежат инструменты: `x-tools/` (`macro11`, `pclink11`, `rt11dsk`) и `x-ukncbtl-debugger/` (консольный эмулятор ukncbtl-debugger с диском RT-11). Без них проверяется только вывод компилятора и эталоны `.MAC`.

## Использование

```
pesto11 [ключи] PROGRAM.PAS
```

Компилятор читает `PROGRAM.PAS` (и файлы, включённые через `{$I ...}`) и пишет рядом с ним:

- `PROGRAM.MAC` — программа;
- `PESTO.MAC` — рантайм: только те подпрограммы, которые нужны программе. С ключом `--onefile` рантайм пишется в конец `PROGRAM.MAC`.

Имя файла программы для RT-11 — не длиннее 6 символов, иначе компилятор выдаёт предупреждение. Шаблон рантайма `runtime-UKNC.tmac` должен лежать рядом с исполняемым файлом компилятора: в дистрибутиве это два файла, `pesto11.exe` и `runtime-UKNC.tmac`.

### Ключи

| Ключ | Действие |
|---|---|
| `-q`, `--quiet` | не печатать заставку |
| `--onefile` | программа и рантайм в одном файле `PROGRAM.MAC` |
| `--platform=UKNC` | целевая платформа; пока поддерживается только `UKNC` (по умолчанию) |
| `--noopt` | выключить оптимизацию списка команд (peephole); оптимизации в генераторе и раскладка переходов работают всегда |
| `-t`, `--tokenizeonly` | вывести лексемы и остановиться |
| `-p`, `--parsingonly` | вывести результат разбора и остановиться |
| `-v`, `--validationonly` | вывести результат проверки (типы, символы, раскладку памяти) и остановиться |
| `-g`, `--showgeneration` | вывести сгенерированный код программы также на консоль |
| `-h`, `--help` | список ключей |

Ключи и имя файла можно писать в любом порядке. Файл — ровно один.

### Ошибки

Ошибки и предупреждения выводятся в виде

```
PROGRAM.PAS(12,5): error 44: Type mismatch: Char is not compatible with Integer
```

(файл, строка, колонка, номер ошибки, текст)

с номерами ошибок Turbo Pascal 3.0 (см. [`docs/TP3-dialect.md`](docs/TP3-dialect.md)). При ошибках `.MAC` не создаётся, код завершения — 1.

### Пример: от исходника до `.SAV`

```sh
pesto11 -q HELLO.PAS
macro11 HELLO.MAC -o HELLO.OBJ -rt11
macro11 PESTO.MAC -o PESTO.OBJ -rt11
pclink11 HELLO.OBJ PESTO.OBJ -EXECUTE:HELLO.SAV
```

`HELLO.SAV` запускается на УКНЦ (или в эмуляторе) командой `RU HELLO`.
